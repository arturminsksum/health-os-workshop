# Health OS (учебная версия) — правила для агента

Этот файл читают и Claude Code (CLAUDE.md), и Codex (AGENTS.md); содержимое одинаковое.

## Что это
Личная медкарта: анализы и заключения врачей превращены в записи с датами, по ним строятся
графики, а Telegram-бот отвечает на вопросы и напоминает о пересдаче. Данные — про ВЫМЫШЛЕННОГО
пациента. Работает на стандартном Python 3.10+, без сторонних библиотек; модель — OpenAI по ключу.

## Где что лежит
- `medcard/<год>/` — анализы: оригинал (PDF, скрин, фото) и рядом `.md` с разбором.
- `medcard/визиты к врачам/` — заключения врачей: фото и разбор.
- `new-documents/` — новые документы для урока, ещё не добавленные в медкарту.
- `data/health-record.json` — главный машинный свод: профиль, показатели с историей, визиты,
  напоминания, короткий статус. Страница и бот читают только его.
- `data/garmin.json` — данные часов за 90 дней и личные нормы.
- `app/` — код: `markers.py` справочник показателей, `medcard.py` приём документов, `ask.py` ответы,
  `bot.py` Telegram-бот и напоминания, `web.py` страница под паролем, `llm.py` вызов OpenAI.
- `dashboard/` — страница медкарты; пересборка: `python3 dashboard/build.py`.
- `run.py` — запуск и проверка; `.env` — ключи и настройки (не в git, пример — `.env.example`).
- `dev/` — генераторы учебных данных, к работе системы не относятся.

## Частые задачи
- **Добавить анализ или заключение:** `python3 run.py add "<файл>" ["<файл>"…]`. Несколько скринов
  одного анализа передавай одной командой. Покажи человеку ответ команды.
- **Ответить на вопрос по медкарте:** `python3 run.py ask "<вопрос>"` или прочитай свод сам.
- **Проверить настройки:** `python3 run.py check`.
- **Запустить страницу и бота:** `python3 run.py` (держит процесс; для фона — см. README).
- **Новый показатель в справочник:** добавь его в `app/markers.py` по образцу (названия на трёх
  языках, единицы, норма, коэффициент mg/dl, если есть).

## Шаги урока
- В `steps/` лежат шаги урока: в каждом `prompts.md` (фразы, с которых начать), `spec.md` (всё, что
  собрано за десятки итераций) и `solution/` (готовое решение).
- **«Подключи готовое решение шага N»** — выполни `python3 run.py step N` и покажи человеку вывод.
  Команда заменяет только код, данные и добавленные анализы не трогает.
- **«Сделай по спеке шага N»** — прочитай `steps/NN-*/spec.md` и сделай всё по нему, потом пересобери страницу.

## Правила
- Единицы — СИ, как в Беларуси и России; mg/dl пересчитывает код по справочнику, оригинал — в скобках.
- Никогда не выдумывай значения. Не видно цифру — так и скажи.
- Не ставь диагнозов и не назначай лечение — только факты из документов и сравнение с прошлым.
- Ключи из `.env` не печатай и не коммить.
- Ответы человеку — на русском, простыми словами.
