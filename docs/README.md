# Рекомендации: что делать дальше после воркшопа

Здесь собран опыт реального личного проекта Health OS, упакованный для тех, кто хочет продолжить сам: как получать от ИИ медицинские отчёты без выдуманных цифр, откуда брать источники, как разбирать данные часов без общих советов и как безопасно хранить медкарту на своём сервере.
Читай в таком порядке: сначала [medical-research-without-hallucinations.md](medical-research-without-hallucinations.md) (метод и рецепт на выходные), затем [sources.md](sources.md) (где брать источники и чем их не подменять), [wearables-analysis.md](wearables-analysis.md) (данные часов и подключение Garmin) и [server-and-privacy.md](server-and-privacy.md) (сервер, что видит поставщик модели, чек-лист перед реальными данными).
Все документы написаны по опыту, а не по учебнику: там, где что-то не проверено, это сказано прямо. Это не медицинская рекомендация, любые выводы про здоровье обсуждай с врачом.
