# Источники для медицинского ресёрча

Здесь собраны источники, которые реально использовались в проекте, и их подводные камни.
Всё, что не подтверждено опытом проекта, помечено «не проверено».
Цены меняются. Колонка «Класс цены» даёт порядок, а не тариф. Актуальные тарифы смотри у провайдера.

## Бесплатные базы (ключ не нужен или бесплатный)

| Источник | Для чего хорош | Подводные камни | Класс цены |
|---|---|---|---|
| PubMed (E-utilities, API от NIH) | Золотой стандарт для поиска статей. Хорошо находит старую классику и исследования по акронимам. | Краткий список результатов приходит без абстракта, только заголовок. Нужна пауза примерно 0,35 с между запросами. При поиске по автору плохо матчится год. | Бесплатно |
| Europe PMC (REST API) | Основной поиск. Включает PubMed/MEDLINE, препринты и часть полных текстов. Умеет сортировать по цитируемости и фильтровать по типу публикации (например, руководства). Отдаёт RSS на сохранённый поиск. | Иногда отвечает 503 или 502, нужны повторы. Поле типа публикации то строка, то список. Плохо находит старую классику по тексту. Платные руководства отдаёт только как абстракт-сводку. | Бесплатно |
| Cochrane через Europe PMC | Золотой стандарт систематических обзоров. Отдельная база не нужна: в Europe PMC фильтруй по журналу Cochrane Database of Systematic Reviews. | Только обзоры, не первичные исследования. Полный текст бывает закрыт. | Бесплатно |
| OpenAlex | Метаданные работ, цитирования, поиск «что новое с даты». | С февраля 2026 года, по нашим записям, нужен бесплатный ключ. Без него выдача была кривой. Обход графа цитирований через него в проекте провалился: граф забивается мегацитируемыми работами не по теме. | Бесплатно (ключ) |
| Semantic Scholar | Дополнительный поиск и метаданные. | Без ключа часто отвечает 429. Не опирайся на него как на единственный источник. | Бесплатно (лучше с ключом) |
| ClinicalTrials.gov (API v2) | Считает, сколько испытаний по теме зарегистрировано, включая неопубликованные. Помогает заподозрить перекос в пользу положительных результатов (publication bias). | Это эвристика-подсказка, а не доказательство. Сам по себе счёт ничего не доказывает. | Бесплатно |

## Руководства (guidelines)

Для практических советов (дозы, красные флаги, когда к врачу) абстрактов исследований мало.
В проекте брали тексты рекомендаций у авторитетных организаций.

| Источник | Для чего хорош | Подводные камни | Класс цены |
|---|---|---|---|
| NICE (guidelines) | Структурированные рекомендации с нумерованными пунктами, включая «не назначать». Бесплатный полный текст. | Британский контекст: препараты и пути оказания помощи могут отличаться в твоей стране. | Бесплатно |
| NICE CKS | Короткие клинические сводки по ситуациям, в том числе без осложнений. | Тот же британский контекст. Есть разделы для соседних групп пациентов, их легко перепутать с твоим случаем. | Бесплатно |
| BNF (British National Formulary) | Справочник по лекарствам: дозы, противопоказания. | Не проверено: условия доступа к полному тексту. Дозы проверяй по локальной инструкции и у врача. | Не проверено |
| USPSTF и профессиональные общества | Рекомендации по скринингу и профилактике. | Полные тексты платных журналов недоступны, в Europe PMC видна только абстракт-сводка без таблиц доз и полного списка красных флагов. | Бесплатно (абстракты) |

Практический приём из проекта: чтобы вытащить руководства из Europe PMC, ищи тематическую фразу в заголовке, ставь фильтр типа публикации «Guideline» и сортируй по цитируемости.
Без фразы в заголовке сортировка по цитируемости возвращает мегацитируемое чужое (щитовидку, диабет, PRISMA).

## Платные и по ключу

| Источник | Для чего хорош | Подводные камни | Класс цены |
|---|---|---|---|
| Exa (нейропоиск с выдачей текста) | Достаёт полные тексты руководств с бесплатных сайтов (NICE, CKS, BNF, USPSTF). Режим выдержек по запросу возвращает именно тексты рекомендаций, а не первые страницы с титулом. | Нужен ключ. Первые 7000 знаков страницы часто содержат только вводную часть. Одно руководство приходит в нескольких форматах, дубли нужно схлопывать по корню адреса и заголовку. В поиск уходит только публичная тема, без данных о человеке. | Платно по использованию |
| OpenAI, Anthropic, Gemini (модели) | Названия ключевых исследований, чтение абстрактов, написание и критика отчёта. Разные провайдеры дают разные слепые пятна. | Недетерминированность. Модели достраивают обрезанное. Ключ может отвалиться (неверный, отозван, кончились деньги), это нужно ловить громко. У некоторых моделей часть параметров (например, temperature) запрещена. | Платно по токенам, глубокий прогон дороже обычного разговора |
| Perplexity API | Поиск с ответами и ссылками. | В проекте не использовался (не было ключа). Ничего не проверено. | Не проверено |

Ориентиры по затратам из проекта.

- Глубокий конвейер с десятками агентов на одну тему: порядка 1,4 млн токенов и около получаса. Стоит несколько долларов. Делай разово для важной темы.
- Лёгкий сбор (модели называют исследования, код ищет их по базам): около полутора минут, копейки.
- Мониторинг новых публикаций раз в две недели: копейки, если фильтр делает дешёвая модель.

Платные надстройки над поиском (Elicit, Undermind, Consensus и подобные) в проекте проверили и не взяли.

- Elicit: независимо измеренная полнота около 40 процентов, подписка, учится на запросах пользователя по условиям сервиса.
- Undermind: лучшая полнота, но API по запросу и долгий поиск.
- Consensus: верх выдачи без идентификаторов статей.
- Эти цифры из разведки июня 2026. Рынок быстро меняется, перепроверь, прежде чем решать.

Вывод проекта: бесплатные базы плюс модели, которые называют, что искать, дали полноту на уровне платного сервиса. Решал спор не маркетинг, а контрольный прогон на теме с известным ответом.

## Как следить за новыми публикациями без своего краулера

Базы отдают это сами.

- PubMed: параметр «за последние N дней» и почтовые оповещения My NCBI.
- Europe PMC: RSS на сохранённый поиск.
- OpenAlex: фильтр по дате добавления.

Прежде чем строить инфраструктуру, проверь, не отдаёт ли её база бесплатно.

## Чем НЕ нужно подтверждать утверждения о здоровье

- Блоги и SEO-сайты про здоровье. Они пишут, чтобы их нашли, а не чтобы было верно.
- Память модели. Если число не пришло из источника в твоём файле, считай его недействительным.
- Пересказ чужого пересказа. Дойди до исследования или руководства.
- Ответ без ссылки или со ссылкой, которую ты не открыл.
- Пост в соцсети. Годится как идея для поиска, не как доказательство.
- Одну статью без проверки типа исследования. Мета-анализ и обзор весят больше, чем одно маленькое испытание.

Одно исключение по смыслу: список «ходовых мифов» по теме можно собрать с обычного интернета.
Это только список вопросов для разбора. Вердикты по каждому мифу бери из собранных научных источников.

## Что отправляется наружу

- В базы статей и в Exa идёт только публичная тема.
- В облачную модель идут вопрос и абстракты статей.
- Данные о здоровье человека (диагноз, возраст, анализы) в эти запросы не добавляй. Подробнее в `server-and-privacy.md`.
