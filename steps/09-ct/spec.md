# Спека: кадры КТ/МРТ с диска клиники

## Что на диске
Копия диска — папка (`ct-disk-copy`): автозапуск, папки программы-просмотрщика и где-то глубоко —
снимок в формате DICOM. Один файл может содержать весь объём (многокадровый, «Enhanced CT»), а может быть
серия — сотни файлов по одному срезу, часто без расширения. Признак DICOM — байты `DICM` со 128-го байта.

## Команда `python3 run.py ct <папка>`
- Новый модуль `app/ct.py`, библиотеки: pydicom, numpy, Pillow (на учебном сервере стоят системными
  пакетами `python3-pydicom`, `python3-numpy`, `python3-pil`; pip там не нужен). Нет библиотеки — понятное
  сообщение, как поставить.
- Найти все DICOM-файлы в папке (по признаку `DICM`, не по расширению). Многокадровый файл — объём целиком;
  серия — отсортировать по `InstanceNumber` (или положению среза) и собрать объём.
- Достать 16 осевых кадров равномерно по объёму (без первых и последних 5% — там обычно пусто), плюс
  по одному центральному коронарному и сагиттальному срезу.
- Окно яркости: по процентилям объёма (1% и 99.5%), чтобы кости и зубы были видны; учитывать
  `RescaleSlope/RescaleIntercept`, если есть.
- Заливку вокруг круглого поля обзора (самое малое значение, если оно занимает больше 1% объёма) исключи
  из расчёта окна, иначе воздух выходит серым.
- Шаг между срезами для коронарного и сагиттального среза бери из положений срезов
  (`ImagePositionPatient` в кадрах), а не из `SpacingBetweenSlices` — иначе картинка сплющена.
- Несколько серий в обследовании — бери самую большую, остальные упомяни в выводе.
- Сохранить кадры JPEG (качество ~85) в `medcard/обследования/<дата> КТ/` и записать `data/imaging.json`:
  список обследований `{date, title, modality, frames: [{name, label, b64}]}` — `b64` — JPEG в base64 для
  страницы одним файлом; `label` — «Осевой срез 7 из 16», «Коронарный срез», «Сагиттальный срез».
- Дата и тип — из полей DICOM (`StudyDate`, `Modality`), заголовок: «КТ, 18 сентября 2025».
- Вывод в терминал: что нашёл (файл, кадров, размер), куда сохранил кадры.
- Добавить команду `ct` в `run.py`.

## Страница
- `dashboard/build.py` подхватывает `data/imaging.json` (если есть) в `window.HEALTH_DATA.imaging`.
- Раздел «Обследования» (🩻) в меню (скрыт, если снимков нет): по каждому обследованию — заголовок, сетка
  кадров 4 в ряд (2 на телефоне), квадратные превью на чёрном фоне, подпись кадра.
- Клик по кадру — просмотр на весь экран: чёрный фон, кадр по центру, подпись, стрелки ← → и свайп листают,
  Esc или клик по фону закрывает.

## Проверка
`python3 run.py ct ct-disk-copy` → 18 кадров; пересобрать страницу; раздел «Обследования» — 16 осевых
срезов челюсти и два центральных; клик открывает кадр на весь экран, стрелки листают.
