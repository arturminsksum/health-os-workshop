# Спека: бот-доктор отвечает на вопросы

## Устройство
- Файлы: `app/bot.py` (Telegram), `app/ask.py` (ответ по медкарте), `app/charts.py` (картинка-график).
  Запуск уже предусмотрен: `python3 run.py bot`.
- Только стандартный Python: Telegram через его HTTP-API, опрос `getUpdates` с долгим ожиданием
  (`timeout=25`, сетевое ожидание на 15 с больше). Картинки — библиотека Pillow (на сервере стоит системным
  пакетом `python3-pil`).
- Модель — через готовый `app/llm.py` (ключ и модель из `.env`). Токен бота — `TELEGRAM_BOT_TOKEN` в `.env`.

## Владелец
Первый, кто написал `/start`, становится владельцем (его id в `data/.bot-owner`); остальным бот не отвечает.
На `/start` — приветствие: «Я веду твою медкарту и отвечаю по ней. Задай вопрос обычными словами — например,
«как менялся мой холестерин?»».

## Ответ на вопрос
- Контекст модели: вся медкарта (`data/health-record.json`), данные часов — нормы и последние 30 дней,
  сегодняшняя дата, последние 3 пары реплик переписки (чтобы понимал «а что было до этого?»).
- Модель отвечает JSON `{text, charts}`: `charts` — ключи показателей для графика.
- Правила для модели (системная инструкция): сначала понять вид вопроса и ответить по правилу —
  1) про свои данные — по медкарте с цифрами и датами, сравнение с нормой и прошлым, ключи в `charts`;
  2) общий медицинский — 2–3 строки простыми словами с привязкой к своим цифрам;
  3) нужен интернет (где пройти, клиники, цены) — одной фразой «искать в интернете пока не умею» и сразу
  полезное из медкарты: что пора сдать; 4) не про здоровье — одна-две строки, что помогаешь с медкартой.
  Без диагнозов и назначений. 2–6 коротких строк, без цепочек цифр через стрелки, даты по-человечески
  («15 сентября 2026»), главные цифры — `**так**`, другой разметки нет.
- Бот переводит `**жирный**` в HTML Telegram, остальное экранирует (текст «< 5.2» не должен ломать разметку).
- Есть ключи в `charts` — бот присылает одну PNG-картинку со столбиком графиков (до 4) и текст подписью;
  длинный текст — отдельным сообщением.

## Картинка-график (Pillow)
Ширина 1000, на показатель панель ~520 высотой: крупное имя, строка «сейчас 3.2 ммоль/л — выше нормы ·
норма < 3.0» цветом статуса, зелёная полоса нормы (обрезана краями), синяя линия, точки по флагу
(зелёный / красный / оранжевый) с подписями значений, годы по оси X. Шрифты крупные (имя ~44, текст ~30) —
читается с телефона. Ось Y по тем же правилам, что графики страницы (шаг 1): по значениям, граница нормы —
только если рядом, минимальный размах 20%. Шрифт: DejaVuSans (Linux) или Arial Unicode (Mac).

## Пока думает
Ответ строится в отдельном потоке (бот не блокируется). Сразу после вопроса — сообщение «🔎 Смотрю медкарту…»
и действие «печатает» каждые 4 секунды; когда ответ готов — служебное сообщение удаляется.

## Проверка
Напиши боту `/start`, потом «как менялся мой холестерин?» — за 5–15 с приходит картинка с графиками
холестерина и LDL и 2–5 строк текста; «где пройти чекап?» — честное «искать в интернете пока не умею» и что сдать.
