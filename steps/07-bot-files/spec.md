# Спека: бот принимает файлы

Нужен шаг 6. Разбор документа уже есть: `medcard.ingest(список_файлов)` — модель читает документ,
код пересчитывает единицы, ставит флаги, раскладывает файлы по папкам медкарты, пишет напоминания из
рекомендаций врача и событие в ленту «Что нового», пересобирает страницу и возвращает текст для человека.

## Приём
- Бот принимает фото (берёт самое крупное), документы (PDF, картинки файлом). Файлы скачиваются в `inbox/`.
- **Сразу**, ещё до скачивания, — сообщение «📄 Получил, читаю документ — секунд 10–20…» и «печатает» каждые 4 с.
- Несколько файлов одним сообщением (альбом, общий `media_group_id`) — один документ: ждём 3 с без новых
  частей, потом разбираем вместе; сообщение обновляется на «📄 Получил 2 файла одного документа, читаю…».
  Одиночный файл — в разбор сразу, без ожидания.
- Пока ждём части альбома, опрос Telegram — короткий (1 с), чтобы не держать альбом.
- Разбор — в отдельном потоке. Готово — служебное сообщение удаляется, приходит ответ `ingest` плюс строка
  «Страница медкарты: <PUBLIC_URL>». Ошибка — «Не получилось разобрать: <причина>».
