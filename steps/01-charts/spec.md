# Спека: графики в разделе «Анализы»

Собрано из ~20 итераций, которые мы прошли сами. Отдай агенту целиком.

## Где и чем
- Файл страницы: `dashboard/index.html`, раздел помечен комментарием `/* ---------- анализы ---------- */`.
- Библиотека графиков Chart.js уже лежит рядом: `dashboard/chart.umd.min.js`. Подключи её строкой
  `<script src="chart.umd.min.js"></script>` перед скриптом страницы — сборка (`python3 dashboard/build.py`)
  сама встроит её в итоговый файл. Никаких загрузок из интернета.
- Данные: `window.HEALTH_DATA.biomarkers` — у каждого показателя `name`, `fullName`, `group`, `unit`, `ref`
  (норма текстом), `low`, `high` (границы нормы, может не быть одной из них) и `series` — список
  `{date, value, flag: "high"|"low"|"ok", lab}`.

## Карточка показателя (вместо строки таблицы)
- Показатели сгруппированы по `group` (Липиды, Обмен веществ, Печень…), карточки — сеткой в две колонки,
  на телефоне (уже 760px) — в одну.
- Шапка карточки: короткое имя крупно, полное имя мелко; справа последнее значение крупно, цветом
  статуса, с единицами; под ним метка «выше нормы» / «ниже нормы» / «в норме».
- Строки: «Норма: …», «Последний: <дата по-человечески> · N замеров».
- Слева у карточки цветная полоса по статусу последнего значения.

## График
- Линия по датам; ось X — годы (дробная позиция внутри года по дате), подписи только целых годов.
- Точки крупные, цвет по флагу: в норме — зелёный `#16a34a`, выше — красный `#dc2626`,
  ниже — оранжевый `#ea8a0c`; белая обводка.
- Норма — светло-зелёная полоса от `low` до `high` (если одной границы нет — до края графика),
  рисуется под линией (плагин `beforeDatasetsDraw`), обрезается краями графика.
- **Ось Y по значениям, а не по норме.** Граница нормы попадает на ось, только если она рядом:
  `near = max(vMax − vMin, |vMax| · 0.1)`; граница учитывается, если лежит в `[vMin − near, vMax + near]`.
  Так ферритин 18–74 при норме 30–400 рисуется до ~80, а не до 400.
- **Минимальный размах:** если размах оси меньше 20% от верхнего значения — расширь симметрично до 20%.
  Так гемоглобин 148 и 151 не выглядит обвалом.
- Запас сверху и снизу 15% размаха.
- Ось X: от начала года первого замера до конца года последнего (минимум один год).
- Ось Y задавай через `suggestedMin` / `suggestedMax`, а не `min` / `max` — тогда Chart.js ставит
  круглые подписи (5.0, 5.5, 6.0), а не 4.9 и 26.05. «Верхнее значение» для минимального размаха —
  верх оси после учёта границ нормы.
- Линия синяя `#2563eb`, толщина 2, лёгкое сглаживание (`tension: 0.2`); точки радиусом 5–6.
- Порядок карточек внутри группы — как в данных; «замер / замера / замеров» склоняй правильно.
- Подсказка при наведении: дата по-человечески, значение с единицами, лаборатория.
- Один замер — график всё равно рисуется (одна точка), без ошибок.
- Высота графика ~200px, без легенды.

## Проверка
- Пересобери: `python3 dashboard/build.py`.
- Открой страницу: у LDL видна полоса нормы < 3.0 и красные точки выше неё; у ферритина ось ~10–80;
  у гемоглобина разница 148 и 151 — небольшая; на телефоне карточки в одну колонку, без горизонтальной прокрутки.
