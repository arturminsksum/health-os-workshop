# Health OS — стартовая версия воркшопа

Личная медкарта: анализы и заключения врачей собраны в одном месте, видно, что выше или ниже нормы и как
менялось с годами. Это **стартовая версия**: красивая страница и медкарта. На уроке вы шаг за шагом
добавляете графики, раскрытие по клику, напоминания, ленту нового, тренды сна и Telegram-бота.

**Шаги урока** — папка `steps/`. В каждом шаге:
- `prompts.md` — с каких фраз агенту начать и как улучшать итерациями;
- `spec.md` — всё, что собрано за десятки итераций, одной спекой;
- готовое решение: не получилось — `python3 run.py step N` (или скажи агенту «подключи готовое решение шага N»).

| Шаг | Что появляется |
|---|---|
| 1 | Графики анализов с нормой |
| 2 | Клик по строке — график и последние значения |
| 3 | Раздел «Напоминания» из рекомендаций врачей |
| 4 | Раздел «Что нового» и подсветка нового |
| 5 | Сон и пульс: тренды, личная норма, простуда |
| 6 | Telegram-бот отвечает на вопросы с графиком |
| 7 | Бот принимает фото, скриншоты и PDF |
| 8 | Кнопки в боте и утренние напоминания |
| 9 | Кадры КТ и МРТ с диска клиники (для быстрых; копия диска — `ct-disk-copy`) |

В репозитории — медкарта **вымышленного** пациента: анализы 2020–2025 на русском, польском и
английском, заключение кардиолога, данные часов за 90 дней. В папке `new-documents` — новые
документы, которые можно добавить.

## Быстрый старт — на своём ноутбуке

Открой приложение с агентом (Claude — вкладка Code, или ChatGPT с Codex), начни сессию в пустой папке и
напиши (вместо КЛЮЧ — ключ OpenAI):

> Скачай проект https://github.com/iamdzennn/health-os-workshop в эту папку. Создай файл .env из
> .env.example и впиши OPENAI_API_KEY=КЛЮЧ. Запусти страницу командой python3 run.py web и дай мне ссылку.

Страница откроется по адресу `http://localhost:8080`. Дальше — шаги урока в папке `steps/`.

### Работа с агентом
В той же папке запусти `claude` (Claude Code) или `codex` (Codex) и проси обычными словами:
«добавь новые документы из папки new-documents», «добавь на страницу график веса». Правила для
агента лежат в `CLAUDE.md` / `AGENTS.md`.

## Свой ключ и свой сервер

**Свой ключ OpenAI.** Создай ключ на platform.openai.com (раздел API keys), положи на счёт
несколько долларов и поставь лимит расходов. Открой `.env` (`nano .env`) и замени значение
`OPENAI_API_KEY=`. Проверь: `python3 run.py check`.

**Свой сервер** (подойдёт любой VPS с Ubuntu 22.04 или новее). Порт 8080 бывает занят другим сервисом — тогда поставь в .env другой, например WEB_PORT=8601:

```
git clone https://github.com/<аккаунт>/health-os-workshop.git health-os
cd health-os
sudo apt install -y python3-pil   # для картинок-графиков в боте
cp .env.example .env
nano .env        # впиши OPENAI_API_KEY, TELEGRAM_BOT_TOKEN, WEB_PASSWORD, PUBLIC_URL
python3 run.py check
python3 run.py
```

Страница откроется по адресу `http://АДРЕС-СЕРВЕРА:8080`. Если не открывается — открой порт:
`sudo ufw allow 8080`.

**Чтобы всё работало после выхода из терминала**, запусти в фоне:

```
nohup python3 -u run.py > health-os.log 2>&1 &
```

**Свои анализы.** Перешли их боту или положи в папку и попроси агента добавить. Вымышленного
пациента можно убрать, попросив агента «очисти медкарту от учебных данных».

Данные в репозитории выдуманы; совпадения с реальными людьми, лабораториями и клиниками случайны.
Система не ставит диагнозов и не заменяет врача.
